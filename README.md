# Telugu Game Night

Party games for Telugu friends, in one web page:

- **Mafia** — the narrator adds everyone's names and deals random roles (Godfather, Mafia, Doctor, Police, Villagers). Each player opens the site on their own phone, enters the game code and taps their number to see their secret role.
- **Dumb Charades** — two teams act out Telugu movies, songs and food against a timer.

No server or sign-in: everything runs in the browser. Hosted with GitHub Pages.
